# Fitness Tracker

A fitness tracking project designed to help users monitor their fitness activities and keep track of their progress.

## Overview
Fitness Tracker is a personal project focused on making fitness activity tracking more organized and accessible. The aim is to help users record relevant fitness information and review their progress over time.

## Features
- Track fitness activities and workout information.
- Organize fitness records for easy reference.
- Review activity data to understand progress.
